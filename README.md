# 너의 옆자리 MVP

공부 기록 + 연애 시뮬레이션 웹 MVP입니다.

## 실행 방법

### 온라인 (GitHub Pages)

https://hwangyoojin5050-lgtm.github.io/kanojo-app/

(저장소에 push 후 Actions 배포가 끝나면 접속 가능)

### 로컬

1. `index.html` 파일을 브라우저로 열기
2. 타이머 시작/정지로 기록 저장
3. 목표 달성률, 호감도, 이벤트 해금, 최근 기록, GitHub 스타일 히트맵 확인

## 포함 기능

- 공부 타이머 시작/정지/리셋
- 과목 선택 후 세션 저장 (`localStorage`)
- 일일 목표 분 설정 및 달성률 표시
- 연속 학습일(10분 이상 기록 기준)
- 공부량 기반 호감도 상승
- 호감도 단계별 대사 변화
- 해금 이벤트 리스트
- GitHub 스타일 공부 시간 히트맵(월~일 정렬)
